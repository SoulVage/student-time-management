# 🎓 Student Study Tracker & AI Assistant

یک سامانه جامع و هوشمند برای برنامه‌ریزی تحصیلی، مدیریت تسک‌ها و تحلیل عملکرد دانش‌آموزان با بهره‌گیری از هوش مصنوعی.

---

## 🚀 درباره پروژه
این پروژه با هدف هوشمندسازی فرآیند مطالعه طراحی شده است. دانش‌آموزان می‌توانند کارهای روزانه خود را ثبت کنند، عملکرد تحصیلی خود را با نمودارهای پیشرفته تحلیل کنند و از دستیار هوشمند برای بهبود روند مطالعه خود کمک بگیرند.

این پلتفرم توسط **امیررضا قاسم‌پور** و **امیرمحمد آذربهرام** (هنرستان فناوران) به عنوان یک ابزار مدیریتی مدرن توسعه یافته است.

---

## 🛠 تکنولوژی‌های استفاده شده
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation:** Framer Motion
- **Icons:** Lucide React
- **Charts:** Recharts

---

## ✨ ویژگی‌های اصلی
*   **AI Chat Assistant:** چت‌بات اختصاصی برای تحلیل داده‌های تحصیلی و پاسخ به سوالات درسی.
*   **Advanced Analytics:** نمایش دقیق پیشرفت درسی با استفاده از نمودارهای تعاملی.
*   **Task Management:** سیستم مدیریت کارهای روزانه و تقویم درسی.
*   **Modern UI:** رابط کاربری تیره/روشن با طراحی متریال و ریسپانسیو.
